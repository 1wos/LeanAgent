문제 설정

증명이 맞아도, 문제가 다를 수 있다

자연어 문제 → Lean statement → 증명 생성 → 검증

Autoformalization의 역할

  • 수학 명제와 증명을 형식 언어로 번역
  • 검증 기반 에이전트의 문제 이해 앞단

놓치기 쉬운 실패

  • 의미가 다른 statement도 컴파일 가능
  • 잘못 번역한 문제의 증명이 성공할 수 있음

번역 품질과 증명 능력은 별도로 점검해야 한다.

평가의 함정

컴파일 성공 ≠ 원문과 같은 정리

번역 결과를 확인해야 한다

  • 구문·타입 체크만으로 의미를 보장 못 함
  • NL2Lean: 컴파일률과 정확도 분리
  • ProofBridge: TC와 SC 분리

벤치마크도 확인해야 한다

  • miniF2F formal–informal 불일치
  • miniF2F-v2: 오류·불일치·단순화 수정
  • 개별 단계 최고 성적 ≠ 전체 성공률
